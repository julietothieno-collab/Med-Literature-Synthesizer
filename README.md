# 🧬 Medical Literature Synthesizer

An AI-powered tool designed for medical students and researchers to synthesize cross-study insights from multiple research papers simultaneously.

## 🌟 Features
- **Multi-PDF Synthesis:** Upload multiple research papers (PDFs) and ask questions across all of them.
- **AI-Driven Clinical Analysis:** Uses Google Gemini Pro to identify trends, conflicting findings, and methodological gaps.
- **Evidence-Based Prompts:** Specifically tuned to provide structured, academic medical responses.
- **Safe & Secure:** API keys are handled via the user interface and never stored in the code.

## 🛠️ Built With
- **Python**
- **Streamlit** (UI Framework)
- **LangChain** (RAG Architecture)
- **Google Gemini Pro** (LLM)
- **FAISS** (Vector Database)

## 🚀 How to Use
1. Get a free Gemini API Key from [Google AI Studio](https://aistudio.google.com/app/apikey).
2. Upload your medical PDFs via the sidebar.
3. Click "Analyze Literature".
4. Enter your research question to generate a synthesized report.
